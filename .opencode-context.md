## Issues Fixed

### 1. C: drive full (0MB free)
- Moved project from `C:\Users\Rudraksh Dixit\soc-lab` → `D:\soc-lab`
- Moved Docker data from `%LOCALAPPDATA%\Docker` → `D:\Docker\Local\` with junction symlink
- Freed ~5.5GB on C:
- C: has ~5.9GB free after also cleaning temp files

### 2. Docker Desktop read-only filesystem
- Caused by full disk → containerd storage went read-only
- Fixed by: wsl --shutdown, taskkill Docker, restart

### 3. SSL cert PEM formatting
- OpenSSL on Windows output single-line PEM (invalid for OpenSearch)
- Fixed with PowerShell function to add 64-char line wrapping
- All .pem and .key files reformatted

### 4. wazuh.indexer-key.pem was a directory
- Accidentally created as directory during cert generation
- Removed and replaced with actual private key file

### 5. internal_users.yml YAML escape errors
- Hash values used double-quoted strings with `\\\.` escape sequences
- YAML rejects unknown escapes like `\.`
- Fixed: switched to single-quoted strings with proper bcrypt hashes

### 6. Security index not initialized
- Auto-init failed due to internal_users.yml parse errors
- Fixed by running securityadmin manually inside the container:
  ```
  export JAVA_HOME=/usr/share/wazuh-indexer/jdk
  /usr/share/wazuh-indexer/plugins/opensearch-security/tools/securityadmin.sh -cd /usr/share/wazuh-indexer/config/opensearch-security -icl -nhnv -cacert /usr/share/wazuh-indexer/config/certs/root-ca.pem -cert /usr/share/wazuh-indexer/config/certs/admin.pem -key /usr/share/wazuh-indexer/config/certs/admin-key.pem -h localhost
  ```
